# Applejack

Applejack V2 is a Python-based CLI compiler/transpiler for 1978 Applesoft BASIC.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .[dev]
```

Run:

```bash
applejack --version
```

Run tests:

```bash
pytest
```
